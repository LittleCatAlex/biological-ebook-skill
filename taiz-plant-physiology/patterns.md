# Taiz Plant Physiology Patterns — 植物生理學核心機制與生奧解題範式

彙整 Lincoln Taiz & Eduardo Zeiger《Plant Physiology (5th Edition)》經典植物生理學重複性架構、生化調控模式與高階實驗推演模型。

---

## 1. 蒸散拉力—內聚力—張力長距離木質部運輸迴路（Transpiration-Cohesion-Tension）
**應用情境**：推導高大林木長距離水分吸收、導管水力傳導度阻力及抗乾旱水力限制。
**運作機制**：
1. **水蒸氣擴散**：葉肉細胞間隙水蒸氣壓高於未飽和大氣，水分經氣孔順蒸氣壓差（$VPD$）擴散進入大氣。
2. **葉肉細胞彎月面負壓生成**：失水使葉肉親水細胞壁微孔隙中之水膜彎月面曲率半徑縮小，依 Young-Laplace 方程式產生高達 $-1.5$ 至 $-3.0\text{ MPa}$ 之極度負毛細管靜水壓（張力）。
3. **氫鍵連續水柱傳遞**：水分子間高抗張強度之氫鍵內聚力（cohesion）將此張力無衰減傳遞至葉脈、莖幹及根部木質部連續導管／假導管。
4. **根系土壤吸水**：導管內之負水勢降至低於土壤水勢（$\Psi_{\text{xylem}} < \Psi_{\text{soil}}$），驅動水分自土壤跨越皮層與內皮層共質體流入中柱。
**極限與代價**：當負張力超過臨界極限時會誘發孔蝕（cavitation）形成氣栓，導致水柱斷裂喪失導水力；壁孔紋膜之微孔表面張力阻止氣泡橫向曼延。

## 2. 保衛細胞氣孔開閉之雙極性離子膨壓控制電路（Stomatal Bipolar Circuit）
**應用情境**：解析氣孔對光照、乾旱逆境、晝夜節律及二氧化碳濃度之極速生理反應。
**運作機制**：
1. **藍光刺激開啟路徑（光合作用模式）**：
   - 藍光活化保衛細胞向光素（PHOT1/PHOT2） $\to$ 刺激質膜 $\text{H}^+$-ATPase 大量泵出質子 $\to$ 原生質膜超極化（電位達 $-140\text{ mV}$ 以下）。
   - 超極化觸發電壓依賴型內向整流 $\text{K}^+_{in}$ 通道開放，$\text{K}^+$ 大量順電位流入；同時藉 $\text{H}^+/\text{Cl}^-$ 共轉運同向吸收氯離子，並在胞質合成蘋果酸二價陰離子（$\text{Malate}^{2-}$）。
   - 離子積累於巨大液胞使保衛細胞 $\Psi_s$ 劇降，吸水建立高達 $+1.5\text{ 至 }+2.0\text{ MPa}$ 之膨壓；由於微纖維徑向輻射狀排列且內壁較厚，保衛細胞向外彎曲張開氣孔。
2. **乾旱逆境 ABA 關閉路徑（節水防禦模式）**：
   - 根冠與葉肉合成之 ABA 抵達保衛細胞結合 PYR/PYL 受體 $\to$ 螯合 PP2C 磷酸酶，釋放 SnRK2 蛋白激酶活化。
   - SnRK2 磷酸化激活慢速陰離子通道 SLAC1，促使 $\text{Cl}^-$ 與蘋果酸大量外流，導致質膜強烈去極化（depolarization）。
   - 膜去極化促使內向 $\text{K}^+_{in}$ 關閉，同時完全開啟外向整流 $\text{K}^+_{out}$ 通道，$\text{K}^+$ 順電位自發外流；溶質大量喪失使保衛細胞滲透失水，膨壓瓦解氣孔關閉。
**競賽關鍵**：藍光為直接訊號（超極化+吸離子）；ABA 為急停訊號（去極化+排離子）。

## 3. 植物激素泛素化『去阻遏（De-repression）』轉錄啟動典範
**應用情境**：解析植物激素（生長素 Auxin、赤黴素 GA、茉莉酸 JA）信號傳導如何極速啟動發育程式。
**運作機制**：
1. **基態靜息鎖定（Braked State）**：無激素時，轉錄因子（ARF, GAMYB, MYC2）被其專一阻遏蛋白（Aux/IAA, DELLA, JAZ）緊密結合並募集去乙醯化酶，染色質緊縮，基因轉錄關閉。
2. **激素受體分子膠水結合**：
   - 生長素直接嵌入 F-box 蛋白 TIR1 與 Aux/IAA 之間的疏水腔，扮演分子膠水。
   - 赤黴素結合可溶性核受體 GID1，誘發 GID1 N端延伸蓋合並結合 DELLA。
3. **E3 泛素連接酶標記與降解**：
   - 形成三元複合體後，募集 $\text{SCF}^{\text{TIR1}}$ 或 $\text{SCF}^{\text{GID2}}$ 泛素連接酶，對阻遏蛋白進行多泛素化修飾。
   - 26S 蛋白酶體極速識別並水解阻遏蛋白（半衰期由數小時縮短至數分鐘）。
4. **轉錄活化（De-repression）**：轉錄因子擺脫束縛，募集 RNA 聚合酶 II 啟動初級響應基因表現。
**演化優勢**：植物體內預先合成好轉錄因子，僅需透過降解單一阻遏蛋白即可達成毫秒至分鐘級之爆發性發育重塑。

## 4. 化學滲透極性生長素運輸（Chemiosmotic Polar Auxin Transport）
**應用情境**：解釋頂芽優勢、向光性向背光側轉移、根部向重力性及側根定位起始。
**運作機制**：
1. **質外體酸性化陷阱**：質膜 $\text{H}^+$-ATPase 使細胞壁空間維持酸性（pH 5.5），生長素主要以未解離且親脂之 IAAH 存在（約 15%），可直接親脂擴散穿透質膜，或由頂端 AUX1 通透酶以 $\text{H}^+$/IAA 同向轉運攝入。
2. **細胞質離子化陷阱**：細胞質為中性（pH 7.0），IAAH 進入後瞬間解離為親水性陰離子 $\text{IAA}^-$（佔 99.9%），無法自由穿透雙層脂質膜。
3. **基底 PIN 蛋白不對稱排出**：$\text{IAA}^-$ 唯有透過極性不對稱定位於細胞基部（下方）質膜的 PIN 家族排出載體流出細胞，進入下方細胞壁。
4. **重力驅動重定位**：根冠平衡柱細胞中，重力使高密度澱粉體沉降於底側，觸發胞內囊泡將 PIN2/PIN3 重新定位至下側質膜，使生長素富集於根下側；根對生長素極敏感，下側高濃度抑制伸長，促成根部向下彎曲生長。
**藥理診斷**：使用 NPA（N-1-萘基鄰苯二甲酸）或 TIBA 處理可專一性抑制 PIN 載體循環，完全阻斷極性運輸與頂芽優勢。

## 5. 光週期臨界夜長計時與開花素（Florigen）FT-FD 調控軸
**應用情境**：判定短日植物（SDP）與長日植物（LDP）在各種日長與夜間光中斷（Night Break）下之開花反應。
**運作機制**：
1. **未中斷夜長沙漏計時**：葉片感光細胞利用光敏素 $P_{fr} \to P_r$ 的黑暗熱回轉與暗中降解計時。短日植物需要夜間連續黑暗時間長於『臨界夜長』方能累積開花訊號。
2. **夜間光中斷（Night Break）機制**：長夜中央給予極微弱紅光閃光（660 nm），瞬間將 $P_r$ 光化學異構化為活化型 $P_{fr}$，使計時器歸零；若緊接著給予遠紅光（730 nm）照射，可將 $P_{fr}$ 變回 $P_r$，完全逆轉光中斷之抑制效應。
3. **葉片 CONSTANS 蛋白穩定化**：長日照下，長日植物葉片在晝夜節律末期受藍光（CRY）與紅光（PHY）照射，保護 CONSTANS（CO）轉錄因子免於被 COP1 泛素化降解，高量 CO 激活葉脈伴細胞中 $FT$ 基因轉錄。
4. **FT 蛋白質作為開花素長距離運送**：小分子 FT 球蛋白透過原形質絲進入篩管，隨韌皮部同化產物流運至莖頂分生組織（SAM）。
5. **FD 互作與花原體啟動**：FT 在莖頂細胞質進入細胞核，與 bZIP 轉錄因子 FD 形成二聚體，專一激活花分生組織認定基因 *APETALA1 (AP1)* 與 *LEAFY (LFY)*，誘導莖頂分生組織轉化為花原體。
