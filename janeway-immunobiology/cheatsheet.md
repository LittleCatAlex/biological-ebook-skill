## 1. High-Yield Immunological Formulas & Constants (重要免疫學定量公式)

### 1.1 抗原-抗體結合親和力方程 (Law of Mass Action)
$$[Ab] + [Ag] \underset{k_d}{\overset{k_a}{\rightleftharpoons}} [Ab-Ag]$$
- **結合平衡常數 (Affinity Constant, $K_A$)**：
  $$K_A = \frac{[Ab-Ag]}{[Ab][Ag]} = \frac{k_a}{k_d} \quad (\text{單位: } \text{M}^{-1} \text{ 或 } \text{L/mol})$$
- **解離平衡常數 (Dissociation Constant, $K_D$)**：
  $$K_D = \frac{1}{K_A} = \frac{[Ab][Ag]}{[Ab-Ag]} = \frac{k_d}{k_a} \quad (\text{單位: } \text{M})$$
  *(高親和力抗體 $K_D$ 通常介於 $10^{-9} \sim 10^{-12} \text{ M}$，即 nM 至 pM 範圍)*

### 1.2 斯卡查德方程 (Scatchard Equation - 結合價與親和力測定)
$$\frac{r}{[c]} = K_A (n - r)$$
- $r$：每個抗體分子平均結合的配體分子數 ($[Ag]_{\text{bound}} / [Ab]_{\text{total}}$)。
- $[c]$：游離游離抗原濃度 ($[Ag]_{\text{free}}$)。
- $n$：每個抗體分子的結合價數 (Valency, 如單體 IgG 之 $n=2$；五聚體 IgM 之理論 $n=10$)。
- **圖解特徵**：以 $r/[c]$ 對 $r$ 作圖，斜率為 $-K_A$，橫軸截距為結合價 $n$。非線性下凹曲線代表抗體多株性或結合存在負協同效應。

### 1.3 補體溶血 50% 滴度計算 (CH50 Assay)
$$\text{von Krogh 方程}: \quad x = K \left( \frac{y}{1 - y} \right)^{1/n}$$
- $y$：溶血百分比 ($0 < y < 1$)。
- $x$：所加入之待測血清體積。
- 當 $y = 0.5$ (50%溶血) 時，$x = K$；$1/K$ 即定義為每毫升血清的 **CH50 單位數**。測定經典途徑整體活性(C1至C9)。

## 5. Primary Immunodeficiency (PID) Rapid Diagnostic Flowchart (原發性免疫缺陷決策樹)

```
懷疑原發性免疫缺陷 (PID) 病患臨床評估？
  │
  ├─► [1] 嚴重反覆性病毒、真菌、胞內菌或伺機性感染 (如鵝口瘡、卡氏肺囊蟲 PJP)？
  │     └─► 檢測外周血 T 細胞計數 (CD3+, CD4+, CD8+)
  │           ├─► T 細胞極度缺乏或功能喪失 ──► **SCID (嚴重合併型免疫缺陷)**
  │           │     ├─ T- B+ NK- ──► **X-linked SCID** (IL2RG 共同 γ 鏈突變)
  │           │     ├─ T- B- NK- ──► **ADA 缺乏症** (腺苷脫氨酶代謝毒性)
  │           │     ├─ T- B- NK+ ──► **RAG1 / RAG2 缺陷** (V(D)J 重排不能)
  │           │     └─ T 細胞少，伴心臟缺損、低血鈣、面容異常 ──► **DiGeorge 症候群** (22q11.2 缺失)
  │           └─► T 細胞數正常但持續鵝口瘡 ──► **APECED** (AIRE 突變) 或 **慢性皮膚黏膜念珠菌病** (IL-17 缺陷)
  │
  ├─► [2] 嬰兒 6 個月後反覆發生胞外包膜化膿菌感染 (肺炎鏈球菌、流感嗜血桿菌之反覆中耳炎、肺炎)？
  │     └─► 檢測血清免疫球蛋白 (IgG, IgA, IgM) 與 B 細胞計數 (CD19+)
  │           ├─► B 細胞完全缺失 (<1%)，全抗體極低 ──► **XLA (Bruton 氏無丙種球蛋白血症)** (BTK 突變)
  │           ├─► B 細胞數量正常，但 IgM 升高/正常，IgG/IgA/IgE 缺失 ──► **高 IgM 症候群**
  │           │     ├─ 男性，伴 PJP 肺囊蟲肺炎 ──► **Type 1 Hyper-IgM** (CD40L 突變，X-linked)
  │           │     └─ 體染色體隱性，無 PJP ──► **Type 2 Hyper-IgM** (AID 酵素突變)
  │           └─► 青年發病，B 細胞數正常但 IgG 與 IgA 顯著低下 ──► **CVID (常變異型免疫缺陷)**
  │
  ├─► [3] 反覆過氧化氫酶陽性菌感染 (金黃色葡萄球菌、麴菌) 形成慢性肉芽腫與淋巴結化膿？
  │     └─► 評估嗜中性球呼吸爆發功能 (DHR 123 流式檢測 或 NBT 還原試驗)
  │           ├─► 呼吸爆發陰性 (無活性氧 ROS 生成) ──► **慢性肉芽腫病 (CGD)** (NADPH 氧化酶 gp91phox 突變)
  │           └─► 巨大溶酶體顆粒、伴眼皮膚白化症 ──► **Chediak-Higashi 症候群** (LYST 突變)
  │
  └─► [4] 白血球計數異常極度升高，但外周感染傷口無膿液形成，伴臍帶脫落延遲 (>30天)？
        └─► 檢測外周白血球表面 CD18 表現量
              └─► CD18 (整合素 β2) 缺失 ──► **白血球黏附缺乏症-1 (LAD-1)**
```
