# Janeway Immunobiology (簡威免疫生物學知識體系)

本 Skill 建基於全球免疫學領域公認最高權威教科書《Janeway's Immunobiology》（第 9 版，Kenneth Murphy & Casey Weaver 著，Garland Science）。提供涵蓋先天免疫、抗原受體多樣性產生、抗原呈現、淋巴球發育與訊息傳遞、效應免疫整合、黏膜屏障、免疫病理（自體免疫、過敏、免疫缺陷）至前沿臨床介入（癌症免疫療法、CAR-T、mRNA 疫苗）的完整知識網絡、解題框架與實驗診斷決策模型，嚴格遵循台灣教育部與國際生物奧林匹亞（IBO）中文審閱規範（全繁體中文台灣標準名詞）。

## When to Use This Skill (何時使用本技能)
- **國際生物奧林匹亞競賽 (IBO / 全國生奧選拔)**：針對抗原受體重排計算、HLA 多型性遺傳、信號轉導路徑阻斷、補體活化級聯及多重免疫缺陷病理高難度題型提供精準推導。
- **免疫學理論與機制深究**：深入探討 TLR/NLR/RLR 模式辨識、MHC class I/II 抗原加工遞呈途徑、胸腺陽性與陰性選擇、胚生中心雙區循環反應(SHM/CSR)與記憶淋巴球分層。
- **免疫病理與臨床診斷評估**：系統鑑別 I～IV 型超敏反應、原發性免疫缺陷病 (SCID, XLA, CGD, Hyper-IgM)、自體免疫病 (SLE, 重症肌無力, T1D) 及器官移植直接/間接排斥與 GVHD。
- **免疫治療與前沿技術分析**：評估單株抗體融合瘤技術、FACS 流式細胞多色分選門控、MHC 四聚體定量、免疫檢查點阻斷 (PD-1/CTLA-4)、CAR-T 細胞工程及 mRNA-LNP 疫苗佐劑機制。

## Core Architecture & Universal Themes (核心架構與通用設計模式)
全書核心邏輯凝練為 [八大通用免疫架構模式](patterns.md)：
1. **多級選殖選擇與自身耐受 (Pattern 1)**：中樞陰性選擇(AIRE)結合周邊 Treg 與克隆失能，平衡防禦多樣性與組織安全性。
2. **組合多樣性與體細胞突變引擎 (Pattern 2)**：RAG 催化 V(D)J 重排創造百億抗原庫，AID 驅動體細胞超突變在胚生中心實現親和力成熟。
3. **雙信號與多信號活化保險機制 (Pattern 3)**：TCR 結合(信號一)必須伴隨 CD28:B7 共刺激(信號二)，缺失信號二誘發永久失能(Anergy)。
4. **隔室化微環境定向歸巢與趨化網絡 (Pattern 4)**：S1P 梯度引導淋巴循環，α4β7/MAdCAM-1 與 CCR9 實現腸道黏膜專屬定位。
5. **ITAM/ITIM 分子開關與激酶級聯 (Pattern 5)**：Src/Syk 激酶磷酸化 ITAM 啟動活化，SHP-1/SHIP 去磷酸化 ITIM 實施負反饋煞車。
6. **效應亞群極化與相互拮抗調控 (Pattern 6)**：Th1 (T-bet)、Th2 (GATA3)、Th17 (RORγt) 正回饋自我鎖定並分泌特徵因子相互抑制。
7. **多價結合親合力與補體擴增級聯 (Pattern 7)**：五聚體 IgM 多價結合引發構形改變，觸發補體 C3 轉化酶的正向放大自催化迴路。
8. **宿主病原軍備競賽與抗原可塑性 (Pattern 8)**：MHC 族群多型性構築防禦長城，反制流感抗原漂移/轉變、錐蟲 VSG 轉換與 HIV 潛伏。
