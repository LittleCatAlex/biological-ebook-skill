# Human Physiology Core Patterns & Regulatory Frameworks
# 人體生理學核心機制模式與調控範式

本文件彙整 Lauralee Sherwood《Human Physiology: From Cells to Systems》人體生理學十大核心生物物理、電生理與神經體液反饋調控範式，提供高階生理學整合分析、動態推演與競賽臨床決策之系統思維模型。

## Pattern 1: 負回饋閉環恆定架構（Negative Feedback Homeostatic Loop）

### 生理本質
負回饋是人體所有器官系統（除生殖系統外）維持細胞外液（ECF）內部環境動態恆定（Dynamic Constancy）的基本架構。當受調控變數（Regulated variable）偏離設定點（Set point）時，系統發動與初始變化相反方向的反應，驅使變數回歸正常範圍。

### 控制理論元件
```
[受調控變數 (如 MAP, 體溫, 血糖)]
       │
       ▼
 [感測器 / 受器 (Sensors/Receptors)] ──(傳入神經 / 激素信號)──► [整合中樞 (Integrating Center)]
                                                                    │ (比對 Set Point 計算偏差)
                                                                    ▼
 [受調控變數回歸正常] ◄──(負回饋抑制)── [動器組織 (Effectors)] ◄──(傳出神經 / 激素輸出)
```

### 系統代表實例
1. **動脈感壓受器反射（Baroreceptor Reflex）**：MAP 驟升 $ightarrow$ 頸動脈竇與主動脈弓感壓受器發放頻率增加 $ightarrow$ 延腦孤立束核（NTS）$ightarrow$ 活化副交感迷走神經（心跳減慢）並抑制交感神經（心肌收縮力減弱、小動脈舒張）$ightarrow$ MAP 迅速降回正常。
2. **血糖恆定控制（Blood Glucose Regulation）**：餐後高血糖 $ightarrow$ 胰島 $eta$ 細胞感應葡萄糖釋放胰島素 $ightarrow$ 促進肝臟、骨骼肌與脂肪攝入葡萄糖合成肝醣 $ightarrow$ 血糖回降；空腹低血糖 $ightarrow$ 胰島 $lpha$ 細胞釋放昇糖素 $ightarrow$ 肝醣分解與糖質新生 $ightarrow$ 血糖回升。

## Pattern 2: 正回饋爆發與自限性終止（Positive Feedback Explosive Cascade）

### 生理本質
正回饋迴路中，動器的輸出進一步強化初始刺激，形成非線性滾雪球效應（All-or-none explosive cascade），用於在極短時間內完成不可逆的重大生理轉折。生理性正回饋必須具備明確的「終止事件（Terminating Event）」，否則將誘發致死性病理紊亂。

```
[初始觸發信號] ──► [受器 / 酵素] ──► [促發效應] ──┐
       ▲                                          │ (正向滾雪球放大)
       └──────────────────────────────────────────┘
                      │
               [外在終止事件] ──► 終止迴路
```

### 系統代表實例
1. **動作電位去極化上升相（Hodgkin Cycle）**：膜去極化至閾值 $ightarrow$ 電壓閘門式 $Na^+$ 通道開啟 $ightarrow Na^+$ 內流 $ightarrow$ 進一步去極化 $ightarrow$ 開啟更多 $Na^+$ 通道；終止事件：$Na^+$ 通道失活門（h gate）延遲關閉與電壓門控 $K^+$ 通道開啟。
2. **分娩佛格森反射（Ferguson Reflex）**：胎頭下降擠壓子宮頸 $ightarrow$ 牽張受器傳入下視丘 $ightarrow$ 腦下垂體後葉釋放催產素 $ightarrow$ 子宮平滑肌強烈收縮 $ightarrow$ 胎頭進一步壓迫子宮頸 $ightarrow$ 催產素釋放更多；終止事件：胎兒完全娩出，子宮頸牽張刺激消失。
3. **血液凝固凝血酶爆發（Thrombin Burst）**：微量凝血酶正回饋活化上游因子 V、VIII、XI，使凝血酶原酶複合物活性幾何級爆發；終止事件：纖維蛋白原耗盡，抗凝血酶與 Protein C 系統全面圍堵。

## Pattern 3: 前饋預期性調控（Feedforward Anticipatory Priming）

### 生理本質
負回饋必須在「偏差已經發生後」才能啟動矯正；前饋控制打破了此時滯限制，利用經驗學習或感官知覺，在受調控變數發生實質偏移前「預先啟動動器」，最小化潛在的波動幅度。

### 系統代表實例
1. **消化頭期分泌（Cephalic Phase of Digestion）**：食物的氣味、視覺或咀嚼動作經大腦皮質與杏仁核，透過迷走神經預先刺激唾液腺、胃壁細胞分泌胃酸與胰島釋放胰島素，在食糜抵達前準備好消化微環境。
2. **運動換氣與心血管前饋預激（Exercise Feedforward Activation）**：大腦運動皮質發起隨意運動指令的同時，側支神經纖維直接興奮延腦心血管中樞與呼吸中樞，在動脈血 $PO_2$ 或 $PCO_2$ 發生任何變化前，即刻拉升心輸出量與肺泡通氣量。

## Pattern 4: 逆流倍增與逆流交換系統（Countercurrent Multiplier & Exchange）

### 生理本質
逆流機制是生物物理在管流對流傳質與傳熱中的極致運用。利用兩個方向相反的平行流體管道，將微小的局部橫向單步梯度（Single effect），藉由軸向流動倍增累積為巨大的縱向垂直梯度。

```
[皮質 Cortical (300 mOsm/L)]
   下行支 (薄壁，只透水，不透鹽)               上行粗支 TAL (厚壁，不透水，主動泵出 NaCl)
       │ (水向外滲透入間質)                          ▲ (主動 NKCC2 泵出鹽分)
       ▼                                            │
   [深層髓質發夾彎 Papilla (1200 mOsm/L)] ──────────┘
```

### 系統代表實例
1. **腎髓質亨利氏環逆流倍增系統**：TAL 頂端膜 NKCC2 主動泵鹽建立 200 mOsm/L 橫向差，下行支失水濃縮，倍增出髓質乳頭 1200 mOsm/L 高滲透環境；集尿管在 ADH 開啟 AQP2 後，水分子順此高滲梯度被動大量抽吸回收。
2. **直管（Vasa Recta）逆流交換**：髮夾狀微血管深入髓質再折返，通透性極高；下行吸鹽失水，上行失鹽吸水，純被動熱交換防止沖洗帶走髓質溶質，保證氧氣供應同時維護滲透梯度。

## Pattern 5: 滑動絲與橫橋動力循環（Cross-Bridge Power Stroke Cycle）

### 生理本質
肌細胞將 ATP 水解之化學自由能轉化為奈米級機械位移的通用分子發動機。肌球蛋白頭部結合肌動蛋白，釋放無機磷酸鹽（Pi）誘發動力衝程拉動肌動蛋白絲滑動，結合新 ATP 誘發解離，水解 ATP 蓄勢復位。

```
[1. 靜止蓄勢態] (Myosin-ADP-Pi, 90° 伸展高能態)
       │ (胞漿 Ca2+ 結合 TnC，暴露出肌動蛋白結合位)
       ▼
[2. 橫橋結合態] (Myosin-Actin 弱結合)
       │
       ▼
[3. 動力衝程 Power Stroke] (釋放 Pi，頭部偏轉 45°，拉動細肌絲朝 M 線滑動 10 nm)
       │
       ▼
[4. 釋放 ADP] (留下短暫僵直複合體 Myosin-Actin)
       │
       ▼
[5. ATP 結合誘導解離] (新鮮 ATP 結合至 Myosin 頭部，橫橋瞬時解離)
       │
       ▼
[6. ATP 水解復位] (Myosin ATPase 水解 ATP 為 ADP+Pi，頭部重置為 90°，回到步驟 1)
```

## Pattern 6: 心臟電機械偶聯與壓力-容積環（Cardiac Cycle & P-V Loop Architecture）

### 生理本質
心室跳動循環在血流動力學上表現為封閉的壓力-容積環（Pressure-Volume Loop）。環的寬度代表心搏量（$SV = EDV - ESV$），環所包圍之幾何面積代表心室每搏做功（Stroke Work）。

```
心室內壓 (mmHg)
  ▲
  │         [收縮末期壓力容積線 ESPVR]
  │               ┌───────────────┐ (主動脈瓣關閉，第二心音 S2)
  │               │   射血期      │
  │ (主動脈瓣開啟)└───────────────┤
  │               │               │
  │        等容收縮期           等容舒張期
  │               │               │
  │ (第一心音 S1) ┌───────────────┴──── (充盈末期 EDPVR)
  │               │    充盈期     │
  └───────────────┴───────────────┴──────────► 心室容積 (mL)
                 ESV             EDV
```
- **前負荷（Preload / EDV）增加**：環向右拓寬，SV 依法蘭克-史達林定律自然增加。
- **後負荷（Afterload / 主動脈阻抗）增加**：環向上拉高變窄，等容收縮期延長，ESV 上升，SV 縮減。
- **收縮力（Inotropy）增強**：ESPVR 線斜率變陡，ESV 下降，射出分率（EF）暴增。

## Pattern 7: 跨微血管流體交換史達林平衡（Starling Microvascular Equilibrium）

### 生理本質
微血管跨壁流體淨移動由流體靜壓差（促過濾）與膠體滲透壓差（促再吸收）之代數和嚴密決定：
$$NFP = (P_c + \pi_{if}) - (P_{if} + \pi_p)$$
- **動脈端（淨過濾 +11 mmHg）**：$P_c (35) + \pi_{if} (1) - P_{if} (0) - \pi_p (25) = +11\text{ mmHg}$。
- **靜脈端（淨再吸收 -9 mmHg）**：$P_c (15) + \pi_{if} (1) - P_{if} (0) - \pi_p (25) = -9\text{ mmHg}$。
- **淋巴回流代償**：每日約 2-4 L 多餘微血管超濾液經盲端毛細淋巴管回收至體循環；若毛細血管壓升高、低白蛋白血症或淋巴受阻，即突破平衡爆發「組織間隙水腫（Edema）」。

## Pattern 8: 內分泌三級反饋調控軸（Three-Tier Endocrine Regulatory Axes）

### 生理本質
神經內分泌系統透過「下視丘釋放激素 $\rightarrow$ 垂體前葉營養性激素 $\rightarrow$ 周邊靶腺實體激素」三階層串聯，實現精確的信號階層放大與長短環自平衡。

```
[中樞神經刺激 / 日夜節律 / 應激]
       │
       ▼
  [下視丘 (Hypothalamus)] ──(TRH, CRH, GnRH, GHRH)
       │                               ▲
       ▼ (門脈系統微量脈衝)               │ (長環負回饋 Long-loop)
[腦下垂體前葉 (Pituitary)] ──(TSH, ACTH, LH/FSH, GH)
       │                               │
       ▼ (全身循環大量傳送)               │
 [周邊目標內分泌腺體] ──(T3/T4, 皮質醇, 性激素, IGF-1) ──┘
       │
       ▼
 [全身廣泛標靶組織細胞生理效應]
```

## Pattern 9: 達文波特酸鹼失衡相圖分析（Davenport Phase-Space Trajectory）

### 生理本質
體液酸鹼失衡由呼吸因素（$PCO_2$）與代謝因素（$[HCO_3^-]$）共同驅動。達文波特圖以 pH 為橫軸、$[HCO_3^-]$ 為縱軸，結合特定 $PCO_2$ 等值線，將酸鹼失衡與代償轉化為直觀的幾何向量軌跡。

1. **急性呼吸性酸中毒**：沿血液化學緩衝線向左上方滑動（$PCO_2 > 45$, pH 跌落，$[HCO_3^-]$ 微升）。
2. **慢性呼吸性酸中毒（腎臟完全代償）**：腎臟排酸保鹼，軌跡垂直向上跨越更高的緩衝線，$[HCO_3^-]$ 顯著拉升，pH 趨近正常下限（7.35）。
3. **代謝性酸中毒**：沿正常 $PCO_2 = 40$ 等值線向左下方直線滑落（$[HCO_3^-] < 22$）；隨後呼吸過度換氣代償（Winter 公式）將軌跡平移至更低之 $PCO_2$ 等值線，拉升 pH。

## Pattern 10: 上皮極性與繼發性主動轉運（Transepithelial Polarized Transport）

### 生理本質
腎小管上皮與小腸腸黏膜上皮透過「緊密接頭（Tight Junctions）」將細胞膜物理區隔為「頂端膜（Apical / Luminal membrane）」與「基底側膜（Basolateral membrane）」。
- **基底側膜引擎**：$Na^+/K^+$ ATPase 將 $Na^+$ 泵出胞外，終生維持細胞內極低之 $[Na^+]$（約 15 mM）與負電位（-70 mV）。
- **頂端膜二次利用**：巨大的跨膜電化學 $Na^+$ 驅動力，被 SGLT（葡萄糖）、NKCC2（鈉鉀二氯）、NHE（鈉氫交換）等同向或反向轉運蛋白借用，驅動營養物質逆濃度梯度泵入細胞內，達成單向淨重吸收。
