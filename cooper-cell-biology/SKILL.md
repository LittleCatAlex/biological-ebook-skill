# Cooper Cell & Molecular Biology (庫柏分子細胞生物學)

本 Skill 建基於經典權威教科書《The Cell: A Molecular Approach》（第 8 版，Geoffrey M. Cooper 著，Oxford University Press）。提供涵蓋分子基礎、遺傳訊息流動、細胞結構功能至細胞週期與癌症調控的完整知識體系、解題框架與實驗決策模型，嚴格遵循台灣教育部與國際生物奧林匹亞審閱標準名詞（全繁體中文）。

## When to Use This Skill (何時使用本技能)
- **分子與細胞生物學問題解析**：解析膜轉運、細胞信號轉導、基因表現調控、細胞骨架動力學與細胞週期檢查點。
- **國際生物奧林匹亞競賽 (IBO / 全國生奧選拔)**：針對生物化學、分子生物學、發育遺傳與腫瘤細胞學高難度題型提供精確推導。
- **生醫實驗設計與技術評估**：針對 PCR、RT-qPCR、Western blot、ChIP-seq、RNA-seq、質譜蛋白質體學、CRISPR/Cas9 基因編輯與單株抗體設計提供標準實驗決策矩陣。
- **精準分子醫學與腫瘤學解析**：探討致癌基因 (Ras, Bcr-Abl)、抑癌基因 (p53, Rb, PTEN)、標靶藥物 (Imatinib, Herceptin) 與免疫檢查點抑制劑 (PD-1, CTLA-4) 之分子機制。

## Core Architecture & Universal Themes (核心架構與通用主題)
1. **空間隔室化與膜界面 (Compartmentalization & Membranes)**：兩性磷脂質自發組裝形成選擇性通透雙層膜，細胞器分工與囊泡運輸（COPI/COPII/Clathrin/SNARE）維持胞內恆定性。
2. **遺傳訊息流動與表觀重塑 (Genetic Flow & Epigenetics)**：中心法則為骨架，轉錄、剪接與轉譯受遠端增強子、三維染色質環、組蛋白密碼與非編碼 RNA 精密調控。
3. **化學滲透與能量偶聯 (Chemiosmosis & Energetics)**：膜電子傳遞鏈泵出質子建立電化學梯度，質子動勢驅動 ATP 合成酶旋轉發電。
4. **分子開關與動態網絡 (Molecular Switches & Networks)**：GTPase 與激酶級聯在時間維度形成雙穩態開關（全或無響應）與負反饋脈衝，確保發育與週期決策的單向不可逆性。
5. **多步校對與品質監控 (Proofreading & Quality Control)**：DNA 聚合酶 3'->5' 外切、tRNA 編輯位點、內質網 Calnexin 循環與 NMD 銷毀機制維持生命最高保真度。

```
遇到細胞生物學問題？
  ├─ 1. 涉及膜轉運或離子流動？
  │     ├─ 小分子/離子 ──► 查閱 ch15 (MacKinnon 鉀通道過濾器, 鈉鉀泵, SGLT1, 能士特方程)
  │     └─ 蛋白質/大分子 ──► 查閱 ch12 (Sec61 轉位子, COPII/COPI/Clathrin, SNARE, M6P)
  ├─ 2. 涉及生長、增殖或信號轉導？
  │     ├─ 膜受體與第二信使 ──► 查閱 ch17 (GPCR, cAMP-PKA, IP3-DAG-Ca2+, RTK-Ras-MAPK, PI3K-Akt)
  │     └─ 細胞週期推進與檢查點 ──► 查閱 ch18 (Cyclin-CDK, Rb-E2F, ATM/ATR-p53-p21, SAC, APC/C)
  ├─ 3. 涉及基因表現、修飾與表觀遺傳？
  │     ├─ 轉錄起始與加工 ──► 查閱 ch08 (Pol II CTD code, 5' Cap, 剪接體轉酯, NMD)
  │     ├─ 染色質重塑與修飾 ──► 查閱 ch09 (增強子, Mediator, 組蛋白乙醯/甲基化, DNA 甲基化)

  └─ 4. 涉及細胞死亡、幹細胞或癌症病理？
        ├─ 凋亡與幹性重編程 ──► 查閱 ch19 (MOMP, Bax/Bak, Apoptosome, Caspase, 山中因子 iPSC)
        └─ 致癌突變與標靶免疫 ──► 查閱 ch20 (Ras/Myc/Bcr-Abl, 雙重打擊假說, Imatinib, PD-1)
```
